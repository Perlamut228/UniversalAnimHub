# Universal Animation Hub

Клиентский хаб анимаций для Roblox (R15): паки, конструктор из отдельных анимаций, каталог эмоций и нормальная поза предмета в руке. Модульный, запускается одной строкой через `loadstring`.

> Всё работает на стороне клиента, это визуальные изменения вашего персонажа. Игра может их блокировать или не реплицировать. Используйте на свой риск и с учётом правил игр и платформы.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Perlamut228/UniversalAnimHub/main/Loader.lua"))()
```

## Возможности

- **Паки.** Классические и удалённые паки с 3D-превью на манекене (анимация при наведении), избранное, поиск по названию и ID.
- **Онлайн-каталог паков.** Поиск анимационных наборов через каталог Roblox, включая снятые с продажи. Найденный набор собирается по названиям ассетов, применяется и сохраняется в список.
- **Конструктор.** Для каждой анимации можно выбрать пак отдельно, как в Roblox: стойка, ходьба, бег, прыжок, лазание, падение, плавание. Пустые слоты берутся из стандартного R15.
- **Пресеты.** Текущую сборку можно сохранить под именем, применить в один клик и удалить.
- **Удаление паков из каталога.** У паков, добавленных из онлайн-каталога, на карточке есть кнопка ✕ (удаляется со второго нажатия). Пак убирается из списка, сборок и пресетов.
- **Эмоции.** Каталог эмоций Roblox с поиском, избранным и миниатюрами. Один клик запускает эмоцию, повторный останавливает. Эмоция сбивается ходьбой, прыжком, лазанием и плаванием (можно отключить).
- **Эмоции Roblox и игры.** `/e dance`, `/e wave`, колесо эмоций и эмоции, экипированные на аватаре, работают поверх кастомного пака. Эмоции из каталога вызываются через `/e <название>` после того, как вы увидели их в списке.
- **Анимации самой игры.** Эмоции и удары предметом, которые проигрывает игра (например, ММ2), поднимаются по приоритету выше пака. Переключатель «Анимации игры поверх пака» в настройках.
- **Предмет в руке.** Нож и другие предметы держатся в позе удержания, а не повторяют анимацию пака. Если игра сама проигрывает анимацию предмета, поза удержания уступает ей. Поддерживаются Slash/Lunge. Переключатель в настройках.
- **Авто-исправление паков.** В фоне сверяет названия ассетов со слотами и переставляет перепутанные анимации. Результат сохраняется.
- **Настройки.** Бинд открытия окна, применение после возрождения, фиксация предмета, поведение эмоций.

## Структура

```
Loader.lua                 загрузчик и общая шина Hub
UniversalAnimHub/
  config.lua               настройки, сохранение, слоты        -> Hub.Config
  packs.lua                база паков                          -> Hub.Packs
  anim.lua                 загрузка треков, авто-исправление   -> Hub.Anim
  emote.lua                движок эмоций                       -> Hub.Emote
  driver.lua               проигрывание анимаций, предметы     -> Hub.Driver
  catalog.lua              каталог Roblox (эмоции и паки)      -> Hub.Catalog
  ui_lib.lua               виджеты, браузер карточек           -> Hub.UILib
  ui_main.lua              окно, вкладки, уведомления          -> Hub.UI
  ui_packs.lua             вкладка «Паки»
  ui_builder.lua           вкладка «Конструктор»
  ui_emotes.lua            вкладка «Эмоции»
  ui_settings.lua          настройки
  startup.lua              применение сохранённого, фоновая проверка паков
```

Модули общаются только через `Hub`. Порядок загрузки задаётся списком `MODULES` в `Loader.lua`: модуль может использовать лишь то, что загружено раньше. Чтобы добавить свой модуль, создайте файл, который начинается с `local Hub = ...`, и допишите его в `MODULES`.

## Что нового (v2.1)

- Поза предмета больше не перекрывает анимации предмета самой игры.
- Анимации игры с низким приоритетом поднимаются выше пака (эмоции, удары).
- Встроенное колесо эмоций и `/e` для эмоций аватара возвращают трек, как родной Animate.
- Пресеты конструктора.
- Удаление паков, скачанных из каталога.

## Настройки и файл данных

Настройки хранятся в `UniversalAnimHub.json` в папке `workspace` экзекьютора: бинд, избранное, выбранная сборка, избранные эмоции, импортированные паки, кэш названий и исправления паков. Чтобы сбросить всё, удалите этот файл.

## Частые проблемы

- **Не грузится модуль.** В консоли будет `[UniversalAnimHub] ошибка загрузки` с именем файла. Проверьте `BASE_URL` и то, что репозиторий публичный. GitHub raw кэширует файлы примерно на пять минут.
- **Каталог пишет, что недоступен.** Экзекьютор не поддерживает `AvatarEditorService:SearchCatalog`. Стандартные эмоции и избранное продолжают работать.
- **Эмоция из каталога не играет.** Часть ассетов не удаётся загрузить напрямую. Скрипт пробует `GetObjects` и прямой ID, но не гарантирует успех для всех.
- **Предмет держится не так, как нужно.** Отключите «Фиксировать предмет в руке» в настройках.
- **Эмоция или удар игры не видны.** Включите «Анимации игры поверх пака». Зацикленные анимации игры с низким приоритетом поднимаются только в первые секунды после того, как взят предмет, поэтому часть таких анимаций может остаться под паком.
- **Эмоции игры не работают.** Включите «Диагностика (консоль F9)» в настройках, нажмите эмоцию и посмотрите строки `[UAH]`: они показывают, вызывает ли игра `PlayEmote`, что именно она передаёт и какие анимации проигрывает.
- **Чужие игроки не видят анимации.** Игра может блокировать или не реплицировать анимации с клиента.

## Источники ID

Классические паки сверены с официальной таблицей Roblox (Creator Docs, «Use animations»). ID Popstar и ряда удалённых паков взяты с вики Roblox. Остальные (спонсорские паки) проверяются в рантайме по названиям ассетов.
